# 逆鐘之城 Clockbound：Godot 版設計規劃

網頁版（repo 根目錄）是第一代原型，數值、技能、刻印、故事都已驗證過；正式版改用 Godot 4，放在 `godot/`。
「直接看效果」與「實際遊戲」都從同一個 Godot 專案匯出（網頁版 / Windows 版），不維護兩套程式。

---

## 1. 視角：2.5D 斜俯視

- 邏輯座標在**地面平面**（x 向右、y 向畫面深處），所有碰撞、距離、範圍都在地面上算。
- 畫面座標：`screen = (x, y × 0.72) - (0, 高度 z)`。地面被壓扁成斜看的樣子，角色和物件是「站著」的立繪。
- 深度排序：依地面 y 排序（越下面越前面），Godot 用 `y_sort_enabled`。
- 牆：後牆露出**正面**（高約 110px），左右牆只露出薄邊，前牆只有矮矮一圈；柱子有頂面＋正面。
- 地面範圍技能（預警、爆炸、火焰地面）一律畫成**橢圓**；子彈飛在離地約 22px 的高度，下方有影子。
- 解析度 1280×720，`canvas_items` 等比縮放，之後換手繪素材也不會糊。

## 2. 角色：零件骨架動畫

每個角色拆成以下零件（之後換成 GPT 畫的 PNG，目前用程式畫的暫代圖）：

| 零件 | 錨點（旋轉中心） | 動作 |
|---|---|---|
| leg_back / leg_front | 臀部 | 跑步擺腿 |
| body（軀幹＋腰） | 腰 | 呼吸、前傾、受擊後仰 |
| head | 脖子 | 跟著軀幹，略延遲 |
| arm_back | 後肩 | 平衡擺動 |
| arm_front | 前肩 | **攻擊主角**，跟著揮擊角度轉 |
| weapon | 握把 | 接在前手末端 |
| cape / hair（選配） | 上端 | 慣性擺動 |

- 只畫面向右的版本，面向左時整個水平翻轉。
- 攻擊方向 360°：身體只分左右，前手和武器轉向滑鼠方向（在 2.5D 投影後的角度）。
- 動作全部用程式算（蓄力 → 揮擊 → 收招），不需要逐格圖；換武器只換 weapon 零件。

## 3. 普攻的代價

| 規則 | 數值（艾琳快劍） | 目的 |
|---|---|---|
| 攻速變慢 | 單刀 0.42s、第三刀 0.62s（原 0.28 / 0.46） | 每一刀都要算時機 |
| 出招中移動變慢 | 移速 ×0.3（蓄力＋收招） | 不能邊跑邊砍 |
| 命中判定在 32% | 蓄力 0.13s 之後才打到 | 要預判，不能貼臉亂按 |
| 揮空硬直 | 沒打到任何敵人，收招 +0.18s | 亂揮有懲罰 |
| 閃避取消 | 只有命中判定之後才能用閃避取消 | 蓄力中被打只能吃下去 |
| 過熱 | 每次普攻 +1 熱度，每秒 -1.3；熱度 ≥ 4 時攻速 ×0.6、冒蒸氣，降到 2 才恢復 | 不能無腦連打，要穿插走位和技能 |
| 發條 | 普攻命中才回發條（不變） | 打中才有資源放技能 |

重劍姿態：單刀 0.75s、0.95s，移速 ×0.2，但第二刀暈眩、傷害高，過熱只 +0.7。

## 5. Godot 專案結構

```
godot/
  project.godot
  scenes/main.tscn          只放 Main 節點，其他全部用程式產生
  scripts/
    iso.gd                  2.5D 座標換算（autoload）
  fonts/                    內嵌中文字型（裁切過，SIL OFL）
    balance.gd              難度曲線、攻擊參數（autoload）
    main.gd                 遊戲流程：樓層、房間、波次、首領、除錯參數
    arena.gd                房間繪製：地板、牆面正面、柱子
    actor.gd                玩家與敵人的共用基底（地面座標、受擊、擊退）
    player.gd               操作、攻擊狀態機、過熱、姿態、技能
    rig.gd                  零件骨架（暫代圖 / PNG 零件）
    enemy.gd                敵人 AI（鼠、衛兵、弩手、甲蟲、術士、傀儡）與首領鏽鐵門衛
    hazard.gd               地面範圍（預警 → 傷害）
    projectile.gd           子彈（有高度與影子）
    pixel_fx.gd             戰鬥特效（粒子 120Hz、上限 500、刀光、衝擊環、光層）
    hud.gd                  血條、發條、熱度、姿態、技能冷卻、首領血條
  art/                      之後放 GPT 畫的零件 PNG（規格見 ART_PROMPTS.md）
```
